---

## 📌 О проекте

**Итоговая тема:**  
RAG-система для ответов на вопросы по нормативным актам Банка России в области кредитного риска.

**Ориентир:** задача №139 — RAG-система / дообучение LLM под домен.  
**Тип задачи:** question answering, генерация текста.  
**Уровень:** PRO.

**Проблема:**  
Пользователям нужны точные ответы по большому корпусу нормативных документов. Обычный поиск по ключевым словам не даёт связного ответа, а LLM без контекста может «галлюцинировать».

**Цель:**  
Построить систему вопрос-ответ по корпусу нормативных актов Банка России в области кредитного риска на основе RAG, оценить качество ответов и предложить меры по снижению галлюцинаций.

**Планируемый результат:**  
RAG-прототип, который по вопросу пользователя находит релевантные фрагменты нормативных актов и формирует ответ со ссылками на источники. При достатке времени — улучшение RAG, сравнение с RAFT/LoRA fine-tuning и добавление агентов для формул и ссылок.

## 🎯 Цель и задачи

### Цель
Создать RAG-систему для ответов на вопросы по нормативным актам Банка России в области кредитного риска, которая:
- опирается на собранный корпус документов;
- выдаёт связные ответы;
- цитирует источники;
- показывает качество выше согласованного порога на тестовом наборе;
- минимизирует галлюцинации.

### Задачи
1. Собрать и подготовить корпус документов.
2. Провести EDA ссылок внутри Положения Банка России № 845-П.
3. Выбрать наиболее часто упоминаемые акты для корпуса.
4. Реализовать парсинг, очистку, чанкинг и метаданные.
5. Построить эмбеддинги и векторный индекс.
6. Реализовать retrieval + генерацию ответа LLM.
7. Сформировать тестовый набор вопросов с эталонами.
8. Оценить качество ответов через RAGAS и/или human eval.
9. Проанализировать неудачные ответы и случаи галлюцинаций.
10. Предложить и проверить улучшения RAG.
11. При наличии времени сравнить RAG с RAFT и добавить агентов для формул/ссылок.
12. Оформить документацию и воспроизводимый pipeline.

## 📚 Корпус документов

За основу берём **Положение Банка России № 845-П**.

Источники:
- ЦБ РФ: https://cbr.ru/Queries/UniDbQuery/File/90134/6231
- Гарант: https://www.garant.ru/products/ipo/prime/doc/411209161/
- docs.cntd.ru: https://docs.cntd.ru/document/1310982660

Рекомендация: для парсинга удобнее скачать HTML-версию из Гаранта.

### EDA по ссылкам
В рамках EDA:
- извлечь из текста 845-П ссылки вида:
  - «Положение Банка России № …»
  - «Инструкция … № …»
- посчитать, какие акты упоминаются чаще всего;
- включить в корпус самые упоминаемые акты;
- остальные акты зафиксировать как ограничения.
